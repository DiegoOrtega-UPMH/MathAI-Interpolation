## Purpose

This assignment explores how linear and polynomial methods can be used to interpolate data. We derive the Lagrange and Newton forms, verify that they produce the same interpolating polynomial for a given set of nodes, and examine how Newton's form can be updated when a new data point is added. We also discuss sensitivity to measurement error and why an exact fit alone does not demonstrate that a model will generalize.

## Topics

1. Linear interpolation and estimates within the interval containing the nodes.
2. Constructing degree-two Lagrange polynomials.
3. Divided differences and Newton's form.
4. Equivalence of the Lagrange and Newton forms for the same data.
5. Cubic interpolation, identifying the function underlying the data, and examining the effect of a hypothetical perturbation.
6. Updating Newton's polynomial incrementally when a fourth node is added.
7. Additional comparisons with natural cubic splines and exploratory leave-one-out validation.
